Camera permissions & teacher settings / 相機權限與設定

Google Chrome

Open the game’s HTTPS link directly in Chrome. Tap Allow Camera, then Allow. If blocked, open the site controls beside the address bar → Site settings / Permissions → Camera → Allow, then reload. Menu names may vary by device.

Safari on iPad

Open the HTTPS link directly in Safari. Tap Allow Camera, then Allow. If blocked, open Safari’s page menu beside the address bar → Website Settings → Camera → Allow or Ask, then reload. You can also check Settings → Apps → Safari → Camera.

The webpage cannot override a camera block. If you are viewing an attachment, Google Drive preview, or an embedded page, open the hosted HTTPS game link directly in your browser. Google Search itself does not grant camera access.
